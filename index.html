Tikro brokerio prijungimas automatiniam pirkimui

Prijunkite Trading 212 arba Alpaca, kad programa pati vykdytų tikrus (arba nemokamus Demo) akcijų bei ETF pirkimus iki 100 €/mėn.

1 variantas (Rekomenduojama Lietuvoje): Trading 212 API (0 € komisiniai, dalinės akcijos nuo 1 €)
  1. Atidarykite Trading 212 programėlę (galite pradėti nuo Practice / Demo režimo be jokios rizikos arba Real Money Invest) → paspauskite Settings → API (Beta) → Generate API key.
  2. Pažymėkite leidimus Account data, Portfolio, Orders ir nukopijuokite API Key bei Secret Key.
  3. Savo GitHub repozitorijoje (banysster-eng/invest-pulsas → Settings → Secrets and variables → Actions) įrašykite šiuos raktus:
    T212_API_KEY, T212_API_SECRET ir T212_ENV (įrašykite demo testavimui arba live tikriems pinigams).
  4. Viskas! Nuo tos akimirkos GitHub serveris automatiškai 3 kartus per darbo dieną patikrins signalus ir vykdys pirkimus/pardavimus griežtai neviršydamas 100 €/mėn. limito!
2 variantas: Tiesioginis Alpaca Markets API telefone (JAV akcijos ir ETF akimirksniu iš telefono)
